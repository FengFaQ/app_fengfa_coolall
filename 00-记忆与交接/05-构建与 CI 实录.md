## CI 配置概况

`.github/workflows/build.yml` 有三个 job：

| Job | 跑在哪 | 做什么 |
| --- | --- | --- |
| `前端检查` | ubuntu-latest | `npm ci` → `typecheck` → `build` |
| `Rust 测试` | ubuntu-latest | `cargo test`（**只测 coolall-core**，不需要 WebKitGTK） |
| `Windows 打包` | windows-latest | `npm run tauri:build` → 上传 artifact |

依赖关系：`Windows 打包` needs 前两个。

## 轮次记录

### 第 1 轮：run 41204567050（失败）

| Job | 结果 | 失败步骤 |
| --- | --- | --- |
| 检查 | ❌ | 前端单元测试 |
| Rust 测试 | ❌ | 运行单元测试（20 个编译错误） |
| Windows 打包 | ⏭ skipped | 被 needs 挡住 |

**三个独立根因**：

1. **vitest 无测试文件** → exit 1
   （`src/` 下 0 个 `*.test.ts`）
2. **MutexGuard 跨 await** → 4 个 future not Send
3. **缺 Manager trait** → `no method manage`
4. **测试 job 没有 dist/** → `generate_context!` panic

**修复**：补测试文件、改 `tokio::sync::Mutex`、`use tauri::Manager`、
测试 job 建占位 dist。

---

### 第 2 轮：run 41205566621（失败）

| Job | 结果 | 失败步骤 |
| --- | --- | --- |
| 前端检查 | ✅ 17s | — |
| Rust 测试 | ✅ 26s | — |
| Windows 打包 | ❌ 4m58s | 构建 |

**关键点**：前两个 job 绿了（拆 crate 生效），
但 Windows 打包一编译 `src-tauri` 就暴露 E0255。

**根因**：`__cmd__*` 宏重复定义 × 14。

**Lead 的错误判断**：以为是 `crate-type = ["staticlib","cdylib","rlib"]` 导致。
**实测证伪**——改成 `["rlib"]` 后本地仍报 E0255。

**真正原因**：命令函数直接定义在 `lib.rs`，而 `lib.rs` 又被 `main.rs` 引用，
宏在模块级命名空间冲突。

**修复**（ci-watcher 建议）：所有命令迁到 `commands.rs`。

---

### 第 3-5 轮：连续被取消

| run | 结果 |
| --- | --- |
| 41206938833 | cancelled（被自己的推送取消） |
| 41207140418 | cancelled |
| 41207561567 | cancelled |

**原因**：`concurrency.cancel-in-progress: true` 是全局的，
每次向 main 推送都会杀掉正在跑的构建。而 Windows 打包要 10 分钟+。

**修复**：改为只在 PR 时取消。

```yaml
concurrency:
  group: build-${{ github.ref }}
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}
```

### 第 6 轮：run 41207794134（构建成功，收集失败）

**这是转折点。**

```log

Running makensis to produce bundle/nsis/coolall_0.1.0_x64-setup.exe
```

**打包完全成功。** 失败的是 Lead 写的 `列出产物` 步骤：

## 获取产物

本机 `github.com` / `objects.githubusercontent.com` 被墙，
**不能直连下载 Release 资产**。必须走 Actions Artifacts API：

```powershell
$tok='<见 .secrets/CREDENTIALS.md>'
$h=@{'Accept'='application/vnd.github+json';'User-Agent'='dsh';'Authorization'="Bearer $tok"}

# 列出产物
$arts = Invoke-RestMethod "https://api.github.com/repos/FengFaQ/app_fengfa_coolall/actions/runs/<RUN_ID>/artifacts" -Headers $h
$arts.artifacts | Select-Object name, size_in_bytes

# 下载（返回 302 到 zip）
Invoke-WebRequest "https://api.github.com/repos/FengFaQ/app_fengfa_coolall/actions/artifacts/<ARTIFACT_ID>/zip" `
  -Headers $h -OutFile coolall.zip -MaximumRedirection 5
```

## 下载失败日志

```powershell
Invoke-WebRequest "https://api.github.com/repos/FengFaQ/app_fengfa_coolall/actions/jobs/<JOB_ID>/logs" `
  -Headers $h -OutFile job.log -MaximumRedirection 5
```

**注意**：返回的是纯文本（223 KB 级别），不是 zip。
曾误以为要解压，实际直接读即可。

日志里有 ANSI 颜色码，清理：

```powershell
Get-Content job.log | ForEach-Object { $_ -replace '\x1b\[[0-9;]*m','' }
```

## 诊断清单（按顺序排查）

CI 失败时，**按这个顺序判断**，不要预先锁定原因：

1. **看是哪个 job 失败**
   - 前端检查 → 类型或构建问题
   - Rust 测试 → 核心 crate 逻辑问题
   - Windows 打包 → 见下

2. **Windows 打包失败时，先看是哪一步**
   - `安装前端依赖` → npm 问题
   - `构建` → 编译问题（`error[E....]`）或打包器问题
   - `列出产物` / `上传产物` → **路径问题，不是打包失败**
   - NSIS 相关（`download` / `nsis` 字样）→ 网络抖动，重跑即可

3. **`构建` 步骤失败时，看错误类型**
   - `error[E0255]` → 命令定义位置（见第 2 轮）
   - `error[E0308]` → 类型不匹配，检查 async/await
   - `future not Send` → Mutex 类型
   - `frontendDist ... doesn't exist` → 缺 dist/

4. **不要预先怀疑图标**
   - 实测图标问题概率最低（第 6 轮成功打包，当时图标是坏的）
   - 若真怀疑，用 §「图标验证」完整解析目录项

## 图标验证方法

只看前 6 字节不够，必须验证目录项偏移：

```powershell
$p = 'src-tauri\icons\icon.ico'
$b = [IO.File]::ReadAllBytes($p)
$count = [BitConverter]::ToUInt16($b,4)
"尺寸数 = $count, 总大小 = $($b.Length) 字节"

for($i=0; $i -lt $count; $i++){
  $off = 6 + $i*16
  $w = $b[$off]; if($w -eq 0){$w=256}
  $size   = [BitConverter]::ToUInt32($b,$off+8)
  $offset = [BitConverter]::ToUInt32($b,$off+12)
  $ok = 'BAD'
  if(($offset + $size) -le $b.Length){ $ok = 'OK' }   # ← 关键检查
  "  ${w}x${w}  size=$size  offset=$offset  $ok"
}
```

**健康输出示例**（6 个尺寸全部 OK）：

```
尺寸数 = 6, 总大小 = 26191 字节
  16x16   size=...  offset=...  OK
  24x24   size=...  offset=...  OK
  32x32   size=...  offset=...  OK
  48x48   size=...  offset=...  OK
  64x64   size=...  offset=...  OK
  256x256 size=...  offset=...  OK
```

**损坏示例**（曾是本项目的状态）：

```
尺寸数 = 1, 总大小 = 2733 字节
数据大小 = 65536
数据偏移 = 177668128     ← 远超文件末尾
```

重新生成：

```powershell
cd src-tauri
npx @tauri-apps/cli icon ./icons/icon.png
```
