### P0-2：Windows 实机验收

按下面的清单逐项跑，**每步给足 20 秒**（全局锁 + 20 秒超时）。

| # | 做什么 | 通过标准 | 失败怎么判断 |
| --- | --- | --- | --- |
| 1 | 运行 `coolall_0.1.0_x64-setup.exe` | 简体中文安装界面，安装完成 | 报错 → 回打包问题 |
| 2 | 启动 exe | 1280×860 窗口，标题 coolall | 白屏 = WebView2 缺失；秒退 = Rust setup panic |
| 3 | 等首屏 | 出现「需要完成人机验证」卡片 | 出列表 = 有缓存，非全新路径；403 = 指纹回归；一直 Loading = IPC 问题 |
| 4 | 点「打开验证页面」 | 浏览器打开 account.coolapk.com | 没反应 = opener 未放行 |

| 6 | 观察首页 | **出列表** | 仍停验证卡片 = `@resolved` 接线问题（已修，确认生效） |
| 7 | 点刷新 | 带凭证正常返回 | 又 1004 = 凭证没保留 |
| 8 | 点「加载更多」 | 追加成功 | 首屏被清空 = 分页逻辑回归 |
| 9 | 点进详情 | 正文 + 评论 | 又弹验证 = 详情页同样要验证（正常） |
| 10 | 搜索 + 翻页 | 正常返回 | — |
| 11 | 详情页点「放弃验证，只看公开页」 | 出现公开页提示 + 清洗后的 HTML | 一直弹验证 = fallback 开关失效 |
| 12 | 重启 exe | validation 不落盘，预期再次 1004；SESSID 应恢复 | 身份 ID 变了 = 持久化失败 |
| 13 | 断网点刷新 | 「连接失败」+ 重试按钮 | 卡死 = 锁/超时问题 |

**快速区分协议问题 vs UI 问题**：

| 界面表现 | 判定 |
| --- | --- |
| 白屏 / 无窗口 / 进程退出 | UI 或外壳 |
| 一直 Loading 超 20 秒 | UI 或 IPC |
| 出现验证卡片 | **协议正常**（1004 被正确识别传递） |
| HTTP 403 | 协议（指纹回归） |
| 「响应格式异常」 | 协议或契约 |
| 详情页好、首页坏 | UI（首页缺 `@resolved`） |
| 所有页面验证后仍 1004 | 协议（validate 拼接或 Cookie 回写） |

**技巧**：详情页是协议健康的探针——它接线完整且支持公开页兜底。
首页失败时先去详情页走一遍，详情好 = 首页 UI 问题。

### P0-3：验证码获取方式

这是**唯一未经真实服务端验证的环节**。

当前做法：打开浏览器 → 用户完成验证 → 粘贴 `validate` 字符串。

若实机验收发现这样拿不到有效 validate，需要改为：
**Tauri 独立 WebView 窗口 + 事件回传**。

设计参考（监督者已给出）：

```rust
pub trait CaptchaFlow: Send + Sync {
    async fn solve(&self, challenge: &CaptchaChallenge) -> CaptchaOutcome;
}

pub enum CaptchaOutcome {
    Validated(String),
    Cancelled,
    TimedOut,
    Unavailable(String),
}
```

要点：oneshot channel + timeout 5 分钟 + 窗口标签限制 + 凭证不进日志。

## 3. 团队协作（重要）

本项目采用多智能体协作，**接手后必须遵守**：

| 角色 | 职责 | 边界 |
| --- | --- | --- |
| Lead（你） | 编码、推送、决策 | 不做长时间轮询 |

5. 向 `ci-watcher` 要结果时，只等它主动发消息，不要反复查

## 6. 关键约束（违反会出问题）

1. **命令必须定义在 `commands.rs`**，放 `lib.rs` 会 E0255
2. **`AppState` 必须用 `tokio::sync::Mutex`**，`std` 的守卫不满足 Send
3. **不要去掉 `BoxFuture` 的 `+ Send`**，Tauri async command 需要
4. **`validation` 凭证不落盘**，只存内存
5. **公开页降级默认关闭**，只有用户放弃验证才开启
6. **每个验证流程只重放一次**
7. **协议版本必须是 16.x**，13.x 会 403
