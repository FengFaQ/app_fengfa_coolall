### TokenV3 关键参数

| 项 | 值 | 易错点 |
| --- | --- | --- |
| `appCode` | `2610291` | 必须等于 `X-App-Code`，不是 2604201 |
| 查找表 | 930 字节 | 切片后还要再做一次 base64 解码 |
| `password` 输入 | **Base64 保留 padding** | **本项目踩过的致命坑** |
| `source` 串 | Base64 **去掉** padding | 与 password 规则相反 |
| 盐末位 | `ALPHABET[(pos - 5) % 64]` | 不能是 `+` |
| 盐末尾 4 位 | 必须为 0 | 否则 bcrypt 拒绝 |
| bcrypt cost | 4 | |
| 输出前缀 | `$2y` | |
| 重试 | 最多 16 个时间戳 | 跳过非法盐 |

## 三、响应结构

首页返回标准包装：

```json
{
  "status": 0,
  "data": [ ... ],
  ...
}
```

- `data` 是数组，长度随推荐流变化
- 单个条目字段见 `_upstream/c001apk/.../model/HomeFeedResponse.kt`
- 实测字节数 212KB ~ 222KB，说明条目数量可观

### 判定成功的标准

```rust
body.contains("\"data\"") && !body.contains("1004")
```

> 注意：不能只看 HTTP 200。1004 也是 HTTP 200。
