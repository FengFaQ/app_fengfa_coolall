### 非交互推送的写法

```powershell
$askDir="$env:TEMP\kuaauth"
New-Item -ItemType Directory -Force -Path $askDir | Out-Null
Set-Content "$askDir\askpass.cmd" '@echo <口令>' -Encoding Ascii
$env:SSH_ASKPASS="$askDir\askpass.cmd"
$env:SSH_ASKPASS_REQUIRE='force'
$env:DISPLAY='dsh'
$env:PATH="$askDir;$env:PATH"
$env:GIT_SSH_COMMAND='ssh -F C:/Users/Administrator/.ssh/config'
git push
```

验证认证：`ssh -F C:/Users/Administrator/.ssh/config -T git@github.com`
应返回 `Hi FengFaQ! You've successfully authenticated`。

### PAT 的已知限制

`api.github.com` 可达，但 `github.com` / `objects.githubusercontent.com`
本机被墙——所以**产物必须走 Actions Artifacts API 取回**，
不能直连 Release 资产。

## 7. 环境恢复清单

若环境丢失，按此顺序重建：

1. 安装 Node.js 22+
2. WSL 中安装 Rust：`curl -sSf https://sh.rustup.rs | sh -s -- -y --profile minimal`
3. WSL 中安装 Tauri 依赖：
   `sudo apt install libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf`
4. `npm install`
5. 从 `Kuan/.secrets/CREDENTIALS.md` 恢复 SSH 与 PAT
6. 若需 Android：从腾讯镜像装 SDK（`mirrors.cloud.tencent.com/AndroidSDK`）
