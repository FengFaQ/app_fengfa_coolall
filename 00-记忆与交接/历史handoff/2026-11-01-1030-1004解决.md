## 根因

TokenV3 的 `password` 输入必须使用**保留 padding** 的 Base64：

```rust
// 错误（我之前的实现）
let password = md5_hex(&b64_nopad(&plain));

// 正确（对齐仓库 1 TokenV3.kt）
let password = md5_hex(&STANDARD.encode(plain.as_bytes()));
```

仓库 1 里 `password` 用 `encoder.encodeToString`（保留 `=`），
只有 `source` 串才用 `withoutPadding`。我把两条规则搞混了。
